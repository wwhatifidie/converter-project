# Конвертер величин

Простая интерактивная программа для перевода длины, массы и температуры.

## Запуск

    python converter.py

## Как пользоваться

1. Запустите программу.
2. Выберите категорию: 1 — длина, 2 — масса, 3 — температура.
3. Введите число.
4. Укажите исходную единицу и единицу, в которую нужно перевести.
5. Получите результат.

## Поддерживаемые единицы

Длина: m, km, cm.

Масса: kg, g, t.

Температура: C, F.

## Требования

Python 3.8 или новее. Сторонние библиотеки не нужны.
